# Gemma Chat

Минималистичный чат с **Gemma 3 27B** (`google/gemma-3-27b-it`) через [OpenRouter](https://openrouter.ai).

**Полностью без бэкенда.** Чистый фронтенд (HTML/CSS/JS, без фреймворков и сборки) — всё работает в браузере:

- Вход по логину/паролю: пароли **не хранятся** — в `public/config.js` лежат только SHA-256 хэши, введённый пароль хэшируется в браузере (Web Crypto) и сравнивается с хэшом.
- Ключ OpenRouter подставляется **только на хостинге**: при деплое из переменной окружения `OPENROUTER_API_KEY` генерируется файл `public/env.js`. В интерфейсе ключа нет — ни ввода, ни отображения.
- Лимит ответа — **1000 токенов** (настраивается в `config.js`).
- **Без истории**: модель видит только текущее сообщение, контекст переписки не отправляется.
- Светлая и тёмная темы: переключатель в шапке, выбор сохраняется в браузере (по умолчанию — как в системе).

## Пользователи

В `public/config.js` пользователи задаются как `логин: sha256("логин:пароль")`.
По умолчанию: **admin / admin123** — поменяйте!

Посчитать хэш для своего пароля:

```bash
node -e "console.log(require('crypto').createHash('sha256').update('ЛОГИН:ПАРОЛЬ').digest('hex'))"
```

## Локальный запуск

Нужен любой статический сервер. В комплекте — крошечный на Node.js без зависимостей:

```bash
npm start            # или: node server.js --port 8080
# открыть http://localhost:8080
```

Для локальной работы создайте `public/env.js` вручную:

```js
const ENV = { apiKey: 'sk-or-v1-...' };
```

Можно и вовсе без сервера — открыть `public/index.html` в браузере
(хэширование через Web Crypto работает и с `file://`).

## Деплой

Это статика: залейте содержимое `public/` на любой статический хостинг
(GitHub Pages, Netlify, Vercel, Timeweb Static и т.п.).

### Встраивание ключа через переменные окружения хостинга

В настройках хостинга заведите переменную `OPENROUTER_API_KEY`, а командой сборки
сгенерируйте `public/env.js`:

```bash
printf 'const ENV={apiKey:"%s"};\n' "$OPENROUTER_API_KEY" > public/env.js
```

`env.js` не коммитится (в `.gitignore`). Если файла нет, чат покажет понятную ошибку.
Через `env.js` также можно переопределить `model` и `maxTokens`.

> Внимание: у чистого фронтенда нет сервера, поэтому встроенный ключ формально виден
> любому, кто откроет код страницы. Ограничьте риск на стороне OpenRouter:
> лимит расхода ключа и, если доступно, привязка по HTTP-Referer.

## Структура

```
server.js          — опциональный статический сервер для локального запуска
public/config.js   — пользователи (SHA-256 хэши), модель, лимит токенов
public/env.js      — генерируется при деплое из переменных окружения (не коммитится)
public/index.html  — разметка
public/style.css   — стили (светлая + тёмная темы)
public/app.js      — вход, темы, логика чата, запросы в OpenRouter
```
