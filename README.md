# Gemma Chat

Минималистичный чат с **Gemma 3 27B** (`google/gemma-3-27b-it`) через [OpenRouter](https://openrouter.ai).

- Чистый фронтенд (HTML/CSS/JS, без фреймворков и сборки) + крошечный сервер на Node.js **без зависимостей**.
  Сервер нужен только для того, чтобы API-ключ и пароли не попадали в браузер.
- Лимит ответа — **1000 токенов**.
- Память — **одно сообщение**: модель видит только предыдущий вопрос и ответ.
- Вход по логину/паролю, сессия хранится в подписанной HttpOnly-cookie (по умолчанию 30 дней).
- Без базы данных: всё настраивается переменными окружения.

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `OPENROUTER_API_KEY` | да | Ключ OpenRouter (`sk-or-...`) |
| `USERS` | да* | Пользователи: `login1:pass1,login2:pass2` |
| `AUTH_LOGIN` / `AUTH_PASSWORD` | да* | Альтернатива `USERS` для одного пользователя |
| `SESSION_SECRET` | желательно | Длинная случайная строка для подписи cookie |
| `PORT` | нет | Порт (по умолчанию `8080`) |
| `MODEL` | нет | Модель OpenRouter (по умолчанию `google/gemma-3-27b-it`) |
| `SESSION_DAYS` | нет | Срок жизни сессии в днях (по умолчанию `30`) |

\* нужен `USERS` или пара `AUTH_LOGIN` + `AUTH_PASSWORD` (можно оба сразу).
Запятая и двоеточие в `USERS` — разделители, поэтому в логинах их использовать нельзя (в паролях нельзя запятую).

Сгенерировать `SESSION_SECRET`:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## Локальный запуск

```bash
OPENROUTER_API_KEY=sk-or-... USERS=admin:secret node server.js
# открыть http://localhost:8080
```

## Деплой на Timeweb Cloud App Platform

1. Залейте репозиторий на GitHub.
2. Timeweb Cloud → **App Platform** → **Создать** → тип **Backend** → **Express** (рантайм Node.js 20+).
3. Подключите GitHub и выберите репозиторий/ветку.
4. Команда запуска: `node server.js` (или оставьте по умолчанию — PM2 сам найдёт `server.js`).
   Команда сборки не нужна (зависимостей нет).
5. В «Расширенных настройках» → **Переменные** добавьте `OPENROUTER_API_KEY`, `USERS` (или `AUTH_LOGIN`/`AUTH_PASSWORD`) и `SESSION_SECRET`.
   Если в настройках приложения указан порт, отличный от `8080`, добавьте ещё `PORT` с этим значением.
6. Задеплойте. HTTPS Timeweb выдаёт сам; cookie автоматически получают флаг `Secure`.

После изменения переменных (например, добавили пользователя) — перезапустите/передеплойте приложение.
