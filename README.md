# Gemma Chat

Минималистичный чат с **Gemma 3 27B** (`google/gemma-3-27b-it`) через [SmartBuddy](https://smartbuddy.ru) — OpenAI-совместимый API, работающий из России без VPN.

**Полностью без бэкенда и без авторизации** — открыл и пользуешься. Чистый фронтенд (HTML/CSS/JS, без фреймворков и сборки):

- Ключ API встроен в `public/config.js` в обфусцированном виде (XOR + base64 — **это не шифрование**, любой посетитель может его восстановить; реальная защита — лимиты бюджета на стороне провайдера). При деплое его можно переопределить переменной окружения хостинга (см. ниже).
- Лимит ответа — **1000 токенов** (настраивается в `config.js`).
- **Без истории**: модель видит только текущее сообщение, контекст переписки не отправляется.
- Светлая и тёмная темы: переключатель в шапке, выбор сохраняется в браузере (по умолчанию — как в системе).
- Не индексируется поисковиками: метатег `noindex` + `robots.txt`.

## Смена провайдера

API любого OpenAI-совместимого провайдера подключается двумя строками в `public/config.js`:

```js
apiBase: 'https://api.smartbuddy.ru/v1',   // базовый URL API
model: 'google/gemma-3-27b-it',            // id модели
```

Например, для OpenRouter: `apiBase: 'https://openrouter.ai/api/v1'`.

## Локальный запуск

Нужен любой статический сервер. В комплекте — крошечный на Node.js без зависимостей:

```bash
npm start            # или: node server.js --port 8080
# открыть http://localhost:8080
```

Можно и вовсе без сервера — открыть `public/index.html` в браузере.

## Замена ключа

Закодировать новый ключ в тот же формат:

```bash
node -e "console.log(Buffer.from([...'ВАШ_КЛЮЧ'].map(c=>c.charCodeAt(0)^0x5A)).toString('base64'))"
```

Результат подставить в `apiKeyEnc` в `public/config.js`.

## Деплой

Это статика: залейте содержимое `public/` на любой статический хостинг
(GitHub Pages, Netlify, Vercel, Timeweb App Platform → тип «Frontend» и т.п.).
Ключ уже встроен в `config.js` — ничего дополнительно настраивать не нужно.

Опционально: если не хотите хранить ключ в репозитории, очистите `apiKeyEnc` и
генерируйте при деплое `public/env.js` из переменных окружения:

```bash
printf 'const ENV={apiKey:"%s"};\n' "$OPENROUTER_API_KEY" > public/env.js
```

`env.js` не коммитится (в `.gitignore`) и имеет приоритет над встроенным ключом.
Через него также можно переопределить `apiBase`, `model` и `maxTokens`.
После изменения переменной нужен передеплой — в статике переменные «зашиваются» при сборке.

## Структура

```
server.js          — опциональный статический сервер для локального запуска
public/config.js   — ключ (обфусцированный), apiBase, модель, лимит токенов
public/env.js      — опционально: переопределения при деплое (не коммитится)
public/index.html  — разметка
public/style.css   — стили (светлая + тёмная темы)
public/app.js      — логика чата, темы, запросы к API
public/logo.jpg    — логотип
public/robots.txt  — не блокирует обход (индексацию запрещает метатег noindex)
```
